# Mini Excel

A spreadsheet program for the Windows console, written in C++. The grid is stored as linked cells.

## Features

- Mouse and keyboard cell selection
- Edit cell contents
- Insert rows and columns, and shift cells right or down
- Delete or clear rows and columns
- Copy, cut and paste
- Range selection with functions such as sum, average and count
- Save a sheet to a file and load it back (`save-load.txt`)

## Requirements

Windows, because the program uses `windows.h` and `conio.h`.

## Build

1. Open `Excel-Project2.sln` in Visual Studio.
2. Build and run.

The code is in `bscs22017.cpp`.
